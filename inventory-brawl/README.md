# Inventory Chaos - Auto Battler Game

Игра в жанре **Inventory Auto-Battler** с использованием PixiJS, SQLite и Express.js.

## 📋 Особенности

- **SQLite база данных** для хранения предметов, врагов, синергий и рецептов крафта
- **Пиксельная графика** без сглаживания
- **Многоклеточные предметы** (мечи, щиты, броня занимают несколько клеток)
- **Drag & Drop** система для размещения предметов
- **Система синергий** - предметы дают бонусы соседям
- **Автоматический бой** с логом событий

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
cd inventory-brawl
npm install
```

### 2. Запуск сервера
```bash
node server.js
```

Сервер запустится на `http://localhost:3000`

### 3. Открыть игру в браузере
Откройте `http://localhost:3000` в любом современном браузере.

## 🎮 Как играть

1. **Фаза магазина**: Покупайте предметы за золото
2. **Размещение**: Перетаскивайте предметы в сетку инвентаря
   - Кликните на предмет в магазине, чтобы взять его
   - Перетащите в сетку и отпустите
   - Нажмите **Пробел** для поворота предмета
3. **Бой**: Нажмите "Начать бой" для автоматического сражения
4. **Победа**: Получите золото и переходите к следующему раунду
5. **Цель**: Достигните 10 побед!

## 🗄️ База данных

Игра использует SQLite (`game_data.db`) со следующими таблицами:

- **items** - все предметы с характеристиками
- **enemies** - типы врагов
- **synergies** - бонусы за соседство предметов
- **crafting_recipes** - рецепты создания предметов
- **player_saves** - сохранения прогресса

## 🔌 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/items` | Все предметы |
| GET | `/api/items/random?count=5` | Случайные предметы для магазина |
| GET | `/api/items/:id` | Предмет по ID |
| GET | `/api/enemies/:difficulty` | Враг по сложности |
| GET | `/api/synergies/:itemId` | Синергии предмета |
| POST | `/api/crafting/check` | Проверка рецепта крафта |
| POST | `/api/save` | Сохранение прогресса |
| GET | `/api/save/:name` | Загрузка сохранения |
| GET | `/api/stats` | Статистика предметов |

## 📦 Предметы

### Оружие
- Деревянный меч (2x1 клетка)
- Стальной меч (3x1 клетка)
- Боевой топор (L-форма 2x2)
- Кинжал (1x1)
- Магический посох (4x1)

### Броня
- Деревянный щит (2x1)
- Стальной нагрудник (2x2)
- Шлем (2x1)

### Еда и зелья
- Хлеб (восстанавливает 10 HP)
- Лечебное зелье (восстанавливает 25 HP)

### Аксессуары
- Камень силы (+15% урона соседям)
- Сапоги скорости (+15% скорость атаки)
- Амулет удачи (+20% крит)

## 🎯 Синергии

- **Стальной меч + Камень силы**: +5 урона
- **Парные кинжалы**: +20% скорость атаки
- **Посох + Камень силы**: -0.5с КД
- **Щит + Шлем**: +5 брони
- **Топор + Сапоги**: +30% скорость атаки

## 🛠️ Технологии

- **Frontend**: PixiJS 7.3.2, HTML5, CSS3
- **Backend**: Node.js, Express.js
- **Database**: better-sqlite3
- **CORS**: Включено для локальной разработки

## 📝 Примечания

- Игра автоматически создаёт базу данных при первом запуске
- Для работы требуется Node.js 14+
- Поддерживается расширение инвентаря до 6x6 клеток
